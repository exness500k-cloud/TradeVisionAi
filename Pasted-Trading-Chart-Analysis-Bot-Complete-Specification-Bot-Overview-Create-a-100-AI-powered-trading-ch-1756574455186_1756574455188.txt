Trading Chart Analysis Bot - Complete Specification
Bot Overview
Create a 100% AI-powered trading chart analysis bot that provides real, accurate trading signals by analyzing chart images and using Ai. The bot should never give random signals and must provide consistent results for the same chart image.


Core Requirements

1. Image Analysis Capabilities
Accept trading chart images (PNG, JPEG, WebP)
File size: 50KB - 5MB
Support candlestick, line, bar, and area charts

Must identify actual market pairs from chart images and using Ai market identify. Generate consistent analysis for same image (no randomness)

2. Market Coverage
Support all market pairs with realistic base prices: Including Real and (OTC) Market 

3. Technical Indicators (12 Total)
Momentum Oscillators:
RSI (14-period)
Stochastic Oscillator
Williams %R

Trend Following:
MACD (Moving Average Convergence Divergence)
ADX (Average Directional Index)
CCI (Commodity Channel Index)

Moving Averages:
MA(20), MA(50), MA(200)

Volatility & Bands:
Bollinger Bands (Upper/Lower)
ATR (Average True Range)

4. Signal Generation Logic
Use multi-indicator confluence analysis
Signal types: "Strong Call", "Call", "Hold", "Put", "Strong Put"
Confidence levels: 45-95%

Signal logic Never random - based on chart Data and Ai chart Detection combinations Detailed logic explanation for each signal

6. User Interface Features
Mobile-first design with dark theme
Drag & drop file upload
Real-time analysis progress


Consistent results - same image = same analysis
Recent analysis history
Professional trading interface
